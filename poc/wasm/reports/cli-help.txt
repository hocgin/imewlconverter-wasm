Description:
  IME WL Converter - 深蓝词库转换
  跨平台的输入法词库转换工具，支持 50+ 种输入法格式

Usage:
  ImeWlConverterCmd [<input-files>...] [options]

Arguments:
  <input-files>  输入词库文件路径（支持多个文件和通配符）

Options:
  -i, --input-format <input-format>      输入词库格式代码 (例如: scel, ggpy, qqpy, rime, bdpy)
  -o, --output-format <output-format>    输出词库格式代码 (例如: ggpy, rime, self, qqpy)
  -O, --output <output>                  输出文件路径或目录路径（目录路径以 / 结尾）
  -f, --filter <filter>                  过滤条件 (例如: "len:1-100|rm:eng|rm:num")
                                           len:1-100    - 保留字数 1-100 的词条
                                           rank:2-9999  - 保留词频 2-9999 的词条
                                           rm:eng       - 移除包含英文的词条
                                           rm:num       - 移除包含数字的词条
                                           rm:space     - 移除包含空格的词条
                                           rm:pun       - 移除包含标点的词条
  -F, --custom-format <custom-format>    自定义格式配置 (用于 self 格式)
                                           格式: <顺序><拼音分隔符><字段分隔符><位置><显示>
                                           示例: "213 ,nyyy" = 词语,拼音(空格分隔),词频
  -t, --code-type <code-type>            编码类型 (pinyin=拼音, wubi=五笔, zhengma=郑码, cangjie=仓颉, zhuyin=注音, userdefine=自定义)
  -c, --code-file <code-file>            自定义编码映射表文件路径（Tab分隔，格式：汉字\t编码）
  -m, --multi-code <multi-code>          多字词编码规则（逗号分隔）
                                           示例: "code_e2=p11+p12+p21+p22,code_e3=p11+p21+p31+p32,code_a4=p11+p21+p31+n11"
  -r, --rank-generator <rank-generator>  词频生成器：固定词频数字（强制覆盖所有词条）或 llm（LLM 生成词频）
                                           示例: -r 100（所有词条词频设为 100）
                                                 -r llm（调用 LLM API 生成词频，需配合 --llm-key 或环境变量 IMEWL_LLM_KEY）
  --llm-endpoint <llm-endpoint>          LLM API 端点（配合 -r llm 使用；默认 https://api.openai.com/v1/chat/completions，自动补全 /v1/chat/completions 后缀）
  --llm-key <llm-key>                    LLM API Key（配合 -r llm 使用；也可通过环境变量 IMEWL_LLM_KEY 提供）
  --llm-model <llm-model>                LLM 模型名称（配合 -r llm 使用，默认 gpt-3.5-turbo）
  --list-formats                         显示所有支持的输入法格式列表
  --json                                 以 JSON 格式输出结果（机器可读；进度不写 stderr，除非同时指定 --verbose）
                                         退出码契约: 0=成功 1=用法错误 2=输入错误 3=部分失败 4=内部错误
  --verbose                              输出详细日志（--json 模式下同时显示进度）
  --dict-id <dict-id>                    导出词库编号（scel 格式内嵌的文件ID，最多6字符，默认随机生成）
  --dict-name <dict-name>                导出词库名称（scel 格式内嵌的元数据，默认: 深蓝词库转换）
  --dict-category <dict-category>        导出词库类别（scel 格式内嵌的元数据，默认: 自定义）
  --dict-description <dict-description>  导出词库描述（scel 格式内嵌的元数据）
  --version                              Show version information
  -?, -h, --help                         Show help and usage information
